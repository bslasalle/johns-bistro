Introduction & Purpose

The Client

Client Name: John O'Barra, Owner and Head Chef

Business Name: John's Bistro

Address: 142 Lisburn Road, Belfast BT9 6AJ

Contact: 028 9012 3456 | hello@johnsbistro.co.uk

John's Bistro is a fictional restaurant located on the Lisburn Road in Belfast. The business serves fresh, honest food using locally sourced ingredients from Northern Irish farms and suppliers. Founded by chef John O'Barra after he trained at La Salle Cookery School, the restaurant has been operating since 2009 and is a well-known and popular spot on the Lisburn Road.

Client Needs

The client has approached me to design and build a website that will serve as the restaurant's primary online presence. The client's requirements are:

  • An attractive, professional website that reflects the character of the restaurant
  • A clear, easy-to-navigate menu showing all food and drink options with prices
  • An online table reservation system so customers can book directly
  • A gallery page showcasing the restaurant's food and interior
  • Information about upcoming events
  • Contact details and a location map
  • A page for seasonal specials that can be updated regularly
  • The website must work well on all modern browsers and be accessible to all users

Purpose of the Website

The website is primarily promotional — it aims to attract new customers and retain existing ones by showcasing the restaurant's offering. It also has a functional element through the online booking form, which allows customers to request table reservations directly without needing to phone. The site will help build the restaurant's brand identity and reputation online.

Target Audience (User Needs)

The users of the website are the members of the public who visit it online. The target audience for John's Bistro includes:

  • Primary: Adults of all ages living in or visiting Belfast who are looking for a good meal out on the Lisburn Road
  • Secondary: Tourists and visitors to Belfast who are searching online for restaurant recommendations in South Belfast
  • Tertiary: People looking for a venue to hold a private event or special occasion dinner

User Needs Include:

  • Easy access to menus and prices before visiting
  • Simple and quick online booking process
  • Clear location, address, and opening hours
  • Visual impression of the food and restaurant
  • Information about upcoming events and seasonal specials
  • Accessibility features for users with visual impairments

📝 Annotation The flat navigation structure was chosen because the website has a relatively small number of pages (8) and users need to be able to access any section quickly — especially Menu and Reservations which are the most commonly needed pages. A hierarchical structure (e.g. sub-menus) was considered but rejected as it adds complexity without benefit for a restaurant site of this size. The navigation bar is sticky (it stays at the top when scrolling), ensuring users can always navigate without scrolling back up.

Navigation Methods Used

  • Sticky Top Navigation Bar — Primary navigation with text links to all 8 pages, always visible
  • Mobile Hamburger Menu — On screens narrower than 860px, the nav bar collapses into a hamburger icon that reveals a dropdown menu
  • In-page Buttons — Buttons like "Book a Table" and "View Menu" on the home page navigate directly to the relevant pages
  • Footer Navigation Links — The footer contains a second set of navigation links for users who reach the bottom of the page
  • External Hyperlinks — The contact page contains external links to Google Maps and TripAdvisor, opening in new tabs

📝 Annotation – Home Page The home page uses a full-screen hero section to make a strong first impression, which is standard practice for restaurant and hospitality websites. The animated background creates visual interest. The features strip uses a dark background to contrast with the light hero, creating visual rhythm. The two-column about teaser introduces the restaurant's story and includes a call-to-action button linking to the About page. This layout meets the client's need to convey quality and warmth immediately on arrival.
Page 2: Menu Page
www.johnsbistro.co.uk — Menu
📝 Annotation – Menu Page The tab system (Starters / Mains / Desserts / Drinks) is an interactive feature that organises the menu without overwhelming the user with all dishes at once. This is especially important on mobile devices where vertical scrolling through a long menu would be frustrating. The Starters tab features five items taken from a real Belfast seafood restaurant menu and rebranded for John's Bistro, including a Soup of the Day, John's Seafood Chowder, Salt & Chilli Squid, Peel & Eat Langoustines, and Dundrum Mussels. Each menu item card uses a gold left border to reinforce the brand. Prices are right-aligned within each card for easy scanning. Allergen information uses short codes (G, F, D, CR etc.) with a key at the bottom of the page, which is standard practice in the catering industry under UK allergen labelling regulations.
Page 5: Gallery Page
www.johnsbistro.co.uk — Gallery
Large
LIGHTBOX OVERLAY (appears on image click)
📝 Annotation – Gallery Page The gallery uses a CSS Grid layout with varied column and row spans to create a dynamic photo grid. Real food and restaurant photographs are used (sourced from Unsplash) rather than placeholder graphics, making the page feel authentic. Each image is styled with a white border and a slight random rotation using CSS transforms, giving the appearance of photos that have been cut and pasted onto the page — this is a deliberate design choice to make the gallery feel more personal and handmade. Hovering over an image straightens it and scales it up. Clicking any image triggers the lightbox JavaScript feature, which displays the photo full-screen in an overlay with a white border frame. The lightbox can be closed by clicking the X button, clicking outside the image, or pressing the Escape key (keyboard accessibility).

Accessibility Features

  • JavaScript Text Resize Tool — A fixed bar at the top of every page contains A+ and A− buttons that increase or decrease the body font size using JavaScript. This is specifically required by the assessment brief.
  • ALT Tags — All image placeholder elements include alt text or aria-label attributes describing the content for screen readers (e.g. alt="Interior of John's Bistro dining room")
  • ARIA Labels — Interactive elements such as the hamburger button, lightbox, gallery items, and nav bar include ARIA labels for screen reader compatibility
  • Semantic HTML — The page uses semantic elements such as <nav>, <footer>, <section>, and <table> with correct structure
  • Keyboard Navigation — The gallery lightbox can be closed using the Escape key; interactive elements are reachable via Tab key
  • Colour Contrast — Text is always placed against sufficiently contrasting backgrounds (dark text on cream, white/gold text on dark) to meet readability standards
  • Responsive Design — The layout adapts to all screen sizes using CSS media queries, ensuring usability on mobile phones, tablets, and desktops
  • Focus Indicators — Form inputs show a gold border on focus, making it clear which field is active for keyboard users

Readability Measures

  • All body text uses minimum 14px font size (and often 15–17px) to ensure readability
  • Line-height is set to 1.7–1.85 for body paragraphs, which research suggests improves readability
  • The colour of grey text (#6b6b6b) against the cream background (#faf6ef) provides sufficient contrast
  • All content has been proofread and spell-checked
  • Headings use a hierarchy (H1 → H2 → H3 → H4) that creates clear visual structure

Section 10

Evaluation

Does the Website Meet the Client's Needs?

Overall I believe the completed website successfully meets all of the client's stated requirements. The restaurant's quality and character are clearly communicated through the dark gold colour scheme, elegant typography, and detailed menu content. The online reservation form provides a direct booking method that the client specifically requested. The specials page can easily be updated to reflect seasonal changes, and the events page keeps customers informed about upcoming activities.

Does the Website Meet the Assessment Checklist?

  • At least 8 pages linked together — ✓ 8 pages: Home, Menu, Specials, About, Gallery, Events, Reservations, Contact
  • Navigation method — ✓ Sticky navigation bar, mobile hamburger menu, in-page button links, footer links
  • CSS (Cascading Style Sheets) — ✓ Extensive CSS including variables, flexbox, grid, animations, media queries
  • Interactive features — ✓ CSS animations, gallery lightbox, menu tabs, form validation, hamburger menu, text resize
  • Functionality — ✓ All navigation, forms, and interactive features tested and working
  • Usability — ✓ Clear navigation, tested in Chrome/Firefox/Edge, flat navigation structure, mobile responsive
  • Readability — ✓ Proofread, spell-checked, sufficient colour contrast, appropriate font sizes and line height
  • Accessibility — ✓ ALT tags, ARIA labels, JavaScript text resize tool, semantic HTML, keyboard navigation

What I Would Improve with More Time

  • Add more real photographs of the actual restaurant interior and food rather than Unsplash stock images
  • Add a real embedded Google Map using the Google Maps API on the contact page
  • Implement a backend server (using Node.js or PHP) to actually process and store reservation requests, sending confirmation emails
  • Add a GDPR-compliant cookie banner and privacy policy page as required for UK websites under the Privacy and Electronic Communications Regulations
  • Add a search/filter function to the menu page so users can filter by allergen or dietary requirement
